# Know Thy Data

---

## Data Objects and Attributes

**Data Objects**: Entities (customers, patients, items)
- Also called: samples, examples, instances, tuples

**Attributes**: Data fields describing objects
- Also called: dimensions, features, variables
- **Attribute vector**: Set of attributes describing an object

---

## Attribute Types: Nominal

**Nominal attributes**: Categorical values without meaningful order
- Examples: hair color, marital status, customer ID
- Values are symbols/names representing categories
- Operations: Only equality/inequality comparisons
- Central tendency: **Mode** (most frequent value)

---

## Attribute Types: Binary

**Binary attributes**: Two states (0 or 1)

**Symmetric binary**: Both states equally important
- Example: gender (male/female)

**Asymmetric binary**: States have different importance
- Example: medical test (positive=1, negative=0)
- Convention: Rarer/more important outcome = 1

---

## Attribute Types: Ordinal

**Ordinal attributes**: Meaningful order, but unknown magnitude between values

**Examples**:
- Drink size: small < medium < large
- Grade: A+, A, A-, B+...
- Satisfaction: very dissatisfied → very satisfied

**Central tendency**: Mode and **median** (not mean)

---

## Attribute Types: Numeric

**Interval-scaled**: Equal-size units, no true zero
- Examples: Temperature (°C, °F), calendar dates
- Can compute: differences, mean, median

**Ratio-scaled**: Has inherent zero-point
- Examples: weight, height, age, temperature (K), monetary amounts
- Can compute: ratios, multiples, all arithmetic operations

---

## Discrete vs Continuous

**Discrete**: Finite or countably infinite values
- Can be nominal, binary, ordinal, or numeric
- Examples: zip codes, customer IDs, age (in years)

**Continuous**: Real values (typically floating-point)
- Examples: temperature, height, weight
- Often used interchangeably with "numeric"

---

## Central Tendency: Mean

**Arithmetic mean**: 
$$\bar{x} = \frac{\sum_{i=1}^{N} x_i}{N}$$

**Weighted mean**:
$$\bar{x} = \frac{\sum_{i=1}^{N} w_i x_i}{\sum_{i=1}^{N} w_i}$$

**Trimmed mean**: Remove top/bottom percentiles before computing

**Limitation**: Sensitive to outliers

---

## Central Tendency: Median & Mode

**Median**: Middle value in sorted data
- N odd: middle value
- N even: average of two middle values
- Robust to outliers, better for skewed data

**Mode**: Most frequently occurring value
- Can be unimodal, bimodal, trimodal, or multimodal
- Works for qualitative and quantitative attributes

**Midrange**: Average of min and max

---

## Data Distribution Shape

**Symmetric**: Mean = Median = Mode

**Positively skewed**: Mode < Median < Mean
- Tail extends right

**Negatively skewed**: Mean < Median < Mode
- Tail extends left

**Empirical relation** (moderate skew):
$$\text{mean} - \text{mode} \approx 3 \times (\text{mean} - \text{median})$$

---

## Dispersion: Range & Quartiles

**Range**: max - min

**Quantiles**: Split data into equal-sized sets
- **Quartiles** (Q₁, Q₂, Q₃): Split into 4 parts
- **Percentiles**: Split into 100 parts

**Interquartile Range (IQR)**: Q₃ - Q₁
- Range of middle 50% of data

**Outlier detection**: Values > 1.5×IQR beyond Q₁ or Q₃

---

## Five-Number Summary & Boxplot

**Five-number summary**:
Minimum, Q₁, Median, Q₃, Maximum

**Boxplot visualization**:
- Box: Q₁ to Q₃ (IQR)
- Line inside box: Median
- Whiskers: Extend to min/max (or 1.5×IQR)
- Individual points: Outliers beyond whiskers

---

## Dispersion: Variance & Standard Deviation

**Variance**:
$$\sigma^2 = \frac{1}{N}\sum_{i=1}^{N}(x_i - \bar{x})^2 = \frac{1}{N}\sum_{i=1}^{N}x_i^2 - \bar{x}^2$$

**Standard deviation**: $\sigma = \sqrt{\sigma^2}$

**Properties**:
- σ = 0 only when no spread
- Measures spread about mean
- **Chebyshev's inequality**: At least $(1 - \frac{1}{k^2}) \times 100\%$ of data within k standard deviations

---

## Graphic Displays: Quantile Plot

**Quantile plot**: All data points plotted against percentiles
- x-axis: f-value (percentile rank)
- y-axis: Data value
- $f_i = \frac{i - 0.5}{N}$

**Shows**:
- Overall distribution
- All individual values
- Q₁, median, Q₃
- Outliers and unusual values

---

## Graphic Displays: Q-Q Plot

**Quantile-Quantile plot**: Compare two distributions
- Plot quantiles of one distribution vs another
- Points along diagonal: Similar distributions
- Deviation from diagonal: Distribution shift

**Use cases**:
- Compare data from different sources
- Test if data follows theoretical distribution
- Identify distribution shifts

---

## Graphic Displays: Histogram

**Histogram**: Frequency distribution for numeric data
- x-axis: Value ranges (bins/buckets)
- y-axis: Frequency (count)
- Typically equal-width bins

**Bar chart**: For nominal attributes
- Each category gets a bar

**Limitation**: Less effective than boxplots for comparing groups

---

## Graphic Displays: Scatter Plot

**Scatter plot**: Bivariate data visualization
- Each point: (x, y) coordinate pair
- Can add 3rd dimension via color/shape

**Reveals**:
- **Positive correlation**: Points slope ↗
- **Negative correlation**: Points slope ↘
- **No correlation**: Random scatter
- Clusters and outliers

---

## Data Visualization: Pixel-Oriented

**Concept**: Each dimension value → colored pixel
- m dimensions → m windows
- Pixel color reflects value
- Global ordering (e.g., sorted by key attribute)

**Space-filling curves**: Better layouts
- Hilbert curve, Gray code, Z-curve
- Keeps adjacent values close

**Circle segments**: Dimensions arranged around circle

---

## Data Visualization: Geometric Projection

**Scatter plot**: 2-D (x, y coordinates)
- Add 3rd dimension: color/shape
- 3-D scatter plot: up to 4 dimensions with color

**Scatter-plot matrix**: n×n grid for n-dimensional data
- Each cell: 2-D projection of two dimensions

**Parallel coordinates**: n parallel axes
- Each data point: polygonal line crossing all axes
- **Limitation**: Visual clutter with many records

---

## Data Visualization: Icon-Based

**Chernoff faces**: Map dimensions to facial features
- Up to 18 variables (36 with asymmetric faces)
- Eyes, nose, mouth, etc. represent dimensions
- Leverages human facial recognition ability
- **Limitation**: Facial features have varying perceived importance

**Stick figures**: Map dimensions to limb angles/lengths
- 2 dimensions → display axes
- Remaining → limb properties
- Dense data shows texture patterns

---

## Data Visualization: Hierarchical

**Worlds-within-Worlds (n-Vision)**:
- Nested 3-D plots
- Inner world origin positioned in outer world
- Interactive: change dimensions and positions

**Tree-maps**: Nested rectangles
- Hierarchical data partitioning
- Rectangle size/color encode values
- Example: Google News categories

---

## Data Visualization: Complex Data

**Tag clouds**: Visualize word/tag frequency
- Font size ∝ importance/frequency
- Alphabetical or preference-based order
- Two uses:
  1. Single item: tag frequency
  2. Multiple items: tag popularity

**Graph visualization**: Network relationships
- Nodes: entities (e.g., diseases)
- Edges: relationships (e.g., correlations)
- Size/width: strength/prevalence

---

## Data Structures for Similarity

**Data matrix** (n×p): Object-by-attribute
- Rows: n objects
- Columns: p attributes
- Two-mode matrix

**Dissimilarity matrix** (n×n): Object-by-object
- Entry d(i,j): dissimilarity between objects i and j
- Properties: d(i,i) = 0, d(i,j) = d(j,i)
- One-mode matrix

---

## Proximity: Nominal Attributes

**Dissimilarity**:
$$d(i,j) = \frac{p - m}{p}$$

where:
- p = total attributes
- m = number of matches

**Range**: [0, 1]
- 0 = identical objects
- 1 = completely different

**Similarity**: $\text{sim}(i,j) = \frac{m}{p} = 1 - d(i,j)$

---

## Proximity: Binary Attributes

**Contingency table**:

| | j=1 | j=0 |
|---|-----|-----|
| i=1 | q | r |
| i=0 | s | t |

**Symmetric binary**:
$$d(i,j) = \frac{r + s}{q + r + s + t}$$

**Asymmetric binary** (ignore negative matches):
$$d(i,j) = \frac{r + s}{q + r + s}$$

**Jaccard coefficient**: $\text{sim}(i,j) = \frac{q}{q + r + s}$

---

## Proximity: Numeric Attributes - Distances

**Euclidean distance** (L₂ norm):
$$d(i,j) = \sqrt{\sum_{f=1}^{p}(x_{if} - x_{jf})^2}$$

**Manhattan distance** (L₁ norm):
$$d(i,j) = \sum_{f=1}^{p}|x_{if} - x_{jf}|$$

**Minkowski distance** (Lₕ norm):
$$d(i,j) = \left(\sum_{f=1}^{p}|x_{if} - x_{jf}|^h\right)^{1/h}$$

---

## Proximity: Numeric Attributes - Properties

**Metric properties** (Euclidean & Manhattan satisfy):
1. **Non-negativity**: d(i,j) ≥ 0
2. **Identity**: d(i,i) = 0
3. **Symmetry**: d(i,j) = d(j,i)
4. **Triangle inequality**: d(i,j) ≤ d(i,k) + d(k,j)

**Supremum distance** (L∞):
$$d(i,j) = \max_f |x_{if} - x_{jf}|$$

**Weighted Euclidean**: Add weights wf to each dimension

---

## Proximity: Ordinal Attributes

**Three-step process**:

1. **Rank**: Replace values with ranks rif ∈ {1,...,Mf}

2. **Normalize**: Map to [0,1]
   $$z_{if} = \frac{r_{if} - 1}{M_f - 1}$$

3. **Compute distance**: Use numeric distance measures on zif

---

## Proximity: Mixed Attribute Types

**Combined dissimilarity**:
$$d(i,j) = \frac{\sum_{f=1}^{p} \delta_{ij}^{(f)} d_{ij}^{(f)}}{\sum_{f=1}^{p} \delta_{ij}^{(f)}}$$

**Indicator** δ(f)ij = 0 if:
- Either value is missing, OR
- Both values are 0 for asymmetric binary

**Contribution** d(f)ij:
- **Numeric**: Normalized difference
- **Nominal/Binary**: 0 if match, 1 if mismatch
- **Ordinal**: Treat as numeric after normalization

---

## Cosine Similarity

**For sparse numeric vectors** (e.g., document term-frequency):

$$\text{sim}(x,y) = \frac{x \cdot y}{||x|| \cdot ||y||}$$

where $||x|| = \sqrt{x_1^2 + x_2^2 + ... + x_p^2}$

**Range**: [0, 1]
- 0 = orthogonal (no similarity)
- 1 = identical direction (maximum similarity)

**Tanimoto coefficient** (binary variation):
$$\text{sim}(x,y) = \frac{x \cdot y}{x \cdot x + y \cdot y - x \cdot y}$$

## Summary

**Key Takeaways**:
- Understand attribute types for proper analysis
- Statistical measures reveal data characteristics
- Visualization exposes patterns and outliers
- Proximity measures enable clustering, classification, outlier detection
- Choose appropriate measure based on data type
