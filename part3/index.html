Purify Thy Data

“Garbage in, garbage out.” — Every data miner, ever.

Real-world data is dirty. Values go missing. Units clash. Records duplicate. Before any mining can begin, data must be cleaned, integrated, reduced, and transformed. This chapter covers the four pillars of data preprocessing — each a step toward trustworthy results.

3.1 Why Data Is Never Born Clean¶

Data quality is defined along six dimensions: accuracy, completeness, consistency, timeliness, believability, and interpretability. In practice, most datasets fail on at least one.

import pandas as pd
import numpy as np

# A typical "raw" employee dataset
raw = pd.DataFrame({
    'name':   ['Alice', 'Bob', 'Bob', None,    'Eve'],
    'age':    [29,       350,   31,    27,      -5],
    'salary': [72000,    85000, 85000, 61000,   None],
    'dept':   ['Eng',    'eng', 'eng', 'Sales', 'SALES'],
})
raw
Note

This one small table has it all: a missing name, an impossible age (350), a duplicate row, an inconsistent category (eng vs Eng), and a missing salary.

3.2 Data Cleaning — Cast Out the Unworthy¶

Data cleaning handles three core problems: missing values, noise/outliers, and inconsistencies.

3.2.1 Missing Values¶

Not all missing values are equal — the right strategy depends on why and how much data is missing.

Common strategies:

StrategyWhen to use
Drop rowMissing at random, dataset large
Fill with mean/medianNumeric, roughly symmetric
Fill with modeCategorical
Model-based imputationHigh-stakes, complex patterns

The Titanic dataset illustrates why the choice matters:

import seaborn as sns
import pandas as pd

df = sns.load_dataset("titanic")
print(df.isnull().sum()[df.isnull().sum() > 0])
age            177
embarked         2
deck           688
embark_town      2

embarked and embark_town have only 2 missing each — safe to drop. age and deck need more thought.

import seaborn as sns
import matplotlib.pyplot as plt

df = sns.load_dataset("titanic")

fig, axes = plt.subplots(1, 2, figsize=(11, 4))

# Age varies strongly by class and sex — group-wise median is smarter than global
sns.boxplot(data=df, x="pclass", y="age", hue="sex", ax=axes[0])
axes[0].set_title("Age by class and sex")
axes[0].set_xlabel("Passenger class")

# Fare overlaps across decks — a poor imputation proxy for deck
sns.boxplot(data=df.dropna(subset=["deck"]), x="deck", y="fare", ax=axes[1])
axes[1].set_ylim(0, 300)
axes[1].set_title("Fare by deck (overlapping — poor proxy)")
axes[1].set_xlabel("Deck")

plt.tight_layout()
plt.show()

age is best filled using group-wise median (by class and sex) — the left panel shows age distributions differ substantially across groups. deck is trickier: fare is a noisy proxy (right panel), and most missing deck values belong to 3rd-class passengers who had no cabin at all (missing not at random) — better flagged than filled.

# Drop trivial missing
df = df.drop(columns=["deck", "embarked", "embark_town"])
df = df.dropna(subset=["embarked"])  

# Smart imputation: group-wise median for age
df["age"] = df.groupby(["pclass", "sex"])["age"].transform(
    lambda x: x.fillna(x.median())
)

print(df.isnull().sum())  # should be 0

3.2.2 Outliers and Noise¶

Tip

Rule of thumb: flag values more than 3 standard deviations from the mean, outside 1.5×IQR from the median, or outside a domain-plausible range (e.g. age ∈ [0, 120]).

Outliers are not always errors — but they always deserve attention. The Adult Census dataset shows workers logging 80–99 hours/week: plausible, but worth flagging for domain review.

3.2.3 Inconsistencies¶

Inconsistencies arise when the same concept appears in multiple forms. The Adult Census workclass column is a good example — self-employment is split into two categories by incorporation status.

from sklearn.datasets import fetch_openml
import pandas as pd

df = fetch_openml('adult', version=2, as_frame=True).frame.dropna()

# workclass has inconsistent self-employment categories
print(df['workclass'].value_counts())

3.3 Data Integration — Unite the Scattered Scrolls¶

Data often lives across multiple sources. Integration merges them into a coherent store, resolving conflicts along the way.

import pandas as pd

# Titanic + port metadata (separate)
titanic = pd.read_csv("https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv")

ports = pd.DataFrame({
    'Embarked':    ['S', 'C', 'Q'],
    'Port':        ['Southampton', 'Cherbourg', 'Queenstown'],
    'Country':     ['England', 'France', 'Ireland'],
})

# Key conflict: 'Embarked' is a code in one, full name in the other
merged = titanic.merge(ports, on='Embarked', how='left')
merged[['Name', 'Pclass', 'Embarked', 'Port', 'Country']].head()

Redundancy check via correlation¶

import numpy as np

# annual_bonus might be derivable from salary — check correlation
salaries = np.array([72000, 85000, 61000])
bonuses  = np.array([5000,  7000,  4500])

r = np.corrcoef(salaries, bonuses)[0, 1]
print(f"Pearson r(salary, bonus) = {r:.3f}")

A high ∣r∣|r|∣r∣ suggests redundancy — consider dropping one attribute before mining.

3.4 Data Reduction — Distill to the Essence¶

Large datasets slow down mining. Reduction shrinks the data while preserving its information content.

3.4.1 Sampling¶

import pandas as pd
import numpy as np

rng = np.random.default_rng(42)
big_dataset = pd.DataFrame({
    'feature_1': rng.normal(50, 10, 10_000),
    'feature_2': rng.exponential(5, 10_000),
})

# Simple random sample — 1% of data
sample = big_dataset.sample(frac=0.01, random_state=42)

print(f"Original: {len(big_dataset):,} rows")
print(f"Sample:   {len(sample):,} rows")
print(f"\nMean feature_1 — full: {big_dataset.feature_1.mean():.2f}, "
      f"sample: {sample.feature_1.mean():.2f}")

3.4.2 Dimensionality Reduction (PCA preview)¶

High-dimensional data is expensive to store, slow to mine, and prone to the curse of dimensionality — distances become meaningless as dimensions grow. PCA finds the directions of maximum variance and projects the data onto a lower-dimensional subspace.

Source
import matplotlib.pyplot as plt
from sklearn.datasets import load_digits
from sklearn.decomposition import PCA

digits = load_digits()
X, y = digits.data, digits.target

pca = PCA(n_components=2)
X2 = pca.fit_transform(X)

fig, ax = plt.subplots(figsize=(8, 6))
scatter = ax.scatter(X2[:, 0], X2[:, 1], c=y, cmap='tab10', alpha=0.5, s=10)
plt.colorbar(scatter, ax=ax, label='Digit')
ax.set_title(f'PCA of handwritten digits — 2 components explain {pca.explained_variance_ratio_.sum():.0%} of variance')
ax.set_xlabel('PC1')
ax.set_ylabel('PC2')
plt.tight_layout()
plt.savefig('pca_digits.png', dpi=150, bbox_inches='tight')
plt.show()
