Know Thy Data

Understanding data structure, characteristics, and patterns is foundational for effective analysis.

Data Objects & Attributes

Data objects represent entities (customers, patients, transactions) described by attributes (features, dimensions, variables).

An **attribute vector** is the set of attributes describing a single object.

Attribute Types

Nominal (Categorical)

Unordered categories without meaningful sequence.

Examples: Hair color, marital status, product ID
Operations: Equality/inequality only
Central tendency: Mode

agtpljgbrbo ipython # Nominal attribute example: iPhone models iphone_models = ['iPhone 15', 'iPhone 16', 'iPhone 15', 'iPhone 17', 'iPhone 15', 'iPhone 16'] import pandas as pd print(f"Most popular model: {pd.Series(iphone_models).mode()}")

Binary

Two states (0 or 1).

Symmetric: Both states equally important (e.g., gender)
Asymmetric: One state more significant (e.g., disease test: positive=1, negative=0)

Convention: Code the rarer/more important outcome as 1.

Ordinal

Meaningful order with unknown magnitude between values.

Examples: - Drink size: small < medium < large - Grade: A+, A, A-, B+… - Satisfaction: 1 (very dissatisfied) → 5 (very satisfied)

Central tendency: Mode, median (not mean)

```python satisfaction = [3, 4, 2, 5, 4, 4, 3, 5, 4, 2] print(f”Median: {np.median(satisfaction)}“) print(f”Mode: {stats.mode(satisfaction, keepdims=True).mode[0]}“) ```

Numeric

Interval-Scaled

Equal-size units, no true zero.

Examples: Temperature (°C, °F), calendar dates
Operations: +, -, mean, median
Limitation: Cannot compute ratios (20°C is NOT 2× warmer than 10°C)

Ratio-Scaled

Has inherent zero-point.

Examples: Weight, height, age, temperature (K), monetary amounts
Operations: All arithmetic including ratios (20kg IS 2× heavier than 10kg)

```{important} Key distinction: Can you meaningfully say “twice as much”? - Yes → Ratio-scaled - No → Interval-scaled ```

Discrete vs Continuous

Discrete: Finite or countably infinite values (zip codes, age in years)
Continuous: Real values, typically floating-point (temperature, height)

Central Tendency

Mean (Arithmetic Average)

\[\\bar{x} = \\frac{\\sum_{i=1}^{N} x_i}{N}\]

Weighted mean: \[\\bar{x} = \\frac{\\sum_{i=1}^{N} w_i x_i}{\\sum_{i=1}^{N} w_i}\]

Trimmed mean: Remove top/bottom percentiles before computing (reduces outlier impact)

```{warning} Highly sensitive to outliers. One extreme value can dramatically shift the mean. ```

Median

Middle value in sorted data. - N odd: exact middle value - N even: average of two middle values

Robust to outliers — preferred for skewed distributions.

Mode

Most frequently occurring value. Works for all attribute types. Data can be: - Unimodal: One mode - Bimodal: Two modes
- Multimodal: Three or more modes

Midrange

Average of minimum and maximum values.

```python salary = [30, 36, 47, 50, 52, 52, 56, 60, 63, 70, 70, 110] print(f”Mean: ${np.mean(salary)}k”) print(f”Median: ${np.median(salary)}k”) print(f”Mode: ${stats.mode(salary, keepdims=True).mode[0]}k”) print(f”Midrange: ${(min(salary) + max(salary))/2}k”) ```

Distribution Shape

Shape Relationship Tail Direction
Symmetric Mean = Median = Mode Balanced
Positively skewed Mode < Median < Mean Right
Negatively skewed Mean < Median < Mode Left

Empirical relation (moderately skewed data): \[\\text{mean} - \\text{mode} \\approx 3 \\times (\\text{mean} - \\text{median})\]

Dispersion Measures

Range

\[\\text{Range} = \\max - \\min\]

Quantiles & Quartiles

Quantiles: Points dividing data into equal-sized consecutive sets

Quartiles split data into 4 parts: - Q₁ (25th percentile): First quartile - Q₂ (50th percentile): Median - Q₃ (75th percentile): Third quartile

Interquartile Range (IQR): \[\\text{IQR} = Q_3 - Q_1\]

Outlier detection rule: Values beyond \(Q_1 - 1.5 \\times \\text{IQR}\) or \(Q_3 + 1.5 \\times \\text{IQR}\)

Five-Number Summary

Minimum, Q₁, Median, Q₃, Maximum

Boxplot visualizes this: - Box spans Q₁ to Q₃ (IQR) - Line inside box: Median - Whiskers extend to min/max (or 1.5×IQR limit) - Individual points beyond whiskers: Outliers

```python import matplotlib.pyplot as plt import seaborn as sns

data = [40, 43, 47, 74, 75, 78, 115, 117, 120] fig, ax = plt.subplots(figsize=(10, 6)) sns.boxplot(data=data, ax=ax) ax.set_ylabel(‘Unit Price ($)’) plt.show() ```

Variance & Standard Deviation

Variance: \[\\sigma^2 = \\frac{1}{N}\\sum_{i=1}^{N}(x_i - \\bar{x})^2 = \\frac{1}{N}\\sum_{i=1}^{N}x_i^2 - \\bar{x}^2\]

Standard deviation: \[\\sigma = \\sqrt{\\sigma^2}\]

Properties: - σ = 0 only when all values identical - Measures spread about the mean - Always use with mean (not median/mode)

```{important} Chebyshev’s inequality: At least \((1 - \\frac{1}{k^2}) \\times 100\\%\) of observations lie within k standard deviations of the mean.

  • k=2: ≥75% within 2σ
  • k=3: ≥89% within 3σ ```

```python prices = [30, 36, 47, 50, 52, 52, 56, 60, 63, 70, 70, 110] mean = np.mean(prices) variance = np.var(prices) std_dev = np.std(prices) print(f”Mean: {mean:.1f}, Variance: {variance:.1f}, Std Dev: {std_dev:.1f}“) ```

Graphic Displays

Quantile Plot

Plots all data points against their percentile ranks.

  • x-axis: f-value (percentile), where \(f_i = \\frac{i - 0.5}{N}\)
  • y-axis: Data value

Shows overall distribution, quartiles, and outliers.

Quantile-Quantile (Q-Q) Plot

Compares quantiles of two distributions.

Interpretation: - Points along diagonal → Similar distributions - Deviation from diagonal → Distribution shift

Use cases: Compare data sources, test theoretical distributions, identify shifts

Histogram

Frequency distribution for numeric data.

  • x-axis: Value ranges (bins/buckets)
  • y-axis: Frequency (count)
  • Typically equal-width bins

Bar chart: Histogram variant for nominal attributes

Scatter Plot

Bivariate visualization using (x, y) coordinates.

Reveals: - Positive correlation: Points slope upward-right ↗ - Negative correlation: Points slope downward-right ↘ - No correlation: Random scatter - Clusters and outliers

Can add 3rd dimension via color/shape, 4th via size.

```{seealso} For correlation strength, compute Pearson’s r or Spearman’s ρ. ```

Advanced Visualization

Pixel-Oriented Techniques

Map each dimension value to a colored pixel.

  • m dimensions → m windows
  • Pixel color reflects value intensity
  • Global ordering (e.g., sorted by key attribute)

Space-filling curves (Hilbert, Gray code, Z-curve) improve layouts by keeping adjacent values spatially close.

Geometric Projection

Scatter plot matrix: n×n grid showing all pairwise 2D projections

Parallel coordinates: n parallel vertical axes, data records as polygonal lines

```{warning} Parallel coordinates suffer from visual clutter with large datasets. ```

Icon-Based

Chernoff faces: Map up to 18 dimensions to facial features (eyes, nose, mouth) - Leverages human facial recognition - Limitation: Feature importance varies perceptually

Stick figures: Map dimensions to limb angles/lengths - Dense data shows texture patterns

Hierarchical

Tree-maps: Nested rectangles encode hierarchical data - Rectangle size/color represent values - Example: File system usage, news categories

Worlds-within-Worlds (n-Vision): Nested 3D plots with interactive dimension manipulation

Similarity & Dissimilarity

Data Structures

Data matrix (n×p): Two-mode matrix - Rows: n objects - Columns: p attributes

Dissimilarity matrix (n×n): One-mode matrix - Entry d(i,j): dissimilarity between objects i and j - Properties: d(i,i) = 0, d(i,j) = d(j,i), d(i,j) ≥ 0

Relationship: \(\\text{sim}(i,j) = 1 - d(i,j)\) (for normalized dissimilarity)

Proximity Measures by Attribute Type

Nominal Attributes

\[d(i,j) = \\frac{p - m}{p}\]

where: - p = total attributes - m = number of matches

Range: [0, 1]
Similarity: \(\\text{sim}(i,j) = \\frac{m}{p}\)

```python def nominal_dissimilarity(obj1, obj2): p = len(obj1) m = sum(1 for a, b in zip(obj1, obj2) if a == b) return (p - m) / p ```

Binary Attributes

Contingency table:

j=1 j=0 Total
i=1 q r q+r
i=0 s t s+t
Total q+s r+t p

Symmetric binary: \[d(i,j) = \\frac{r + s}{q + r + s + t}\]

Asymmetric binary (ignore negative matches): \[d(i,j) = \\frac{r + s}{q + r + s}\]

Jaccard coefficient: \[\\text{sim}(i,j) = \\frac{q}{q + r + s} = 1 - d(i,j)\]

```{tip} Use asymmetric distance when both=0 is uninformative (e.g., disease symptoms, document keywords, rare events). ```

Example: Smoking vs Cancer

```python # Contingency table # Cancer No Cancer # Smoker 50 150 # Non-smoker 10 790

q, r, s, t = 50, 150, 10, 790

Asymmetric dissimilarity

d_asymm = (r + s) / (q + r + s) print(f”Dissimilarity: {d_asymm:.2f}“)

Jaccard similarity

jaccard = q / (q + r + s) print(f”Jaccard: {jaccard:.2f}“)

Chi-square test

from scipy.stats import chi2_contingency observed = [[q, r], [s, t]] chi2, p_value, dof, expected = chi2_contingency(observed) print(f”Chi-square: {chi2:.2f}, p-value: {p_value:.4f}“) ```

Numeric Attributes

Euclidean distance (L₂ norm): \[d(i,j) = \\sqrt{\\sum_{f=1}^{p}(x_{if} - x_{jf})^2}\]

Manhattan distance (L₁ norm): \[d(i,j) = \\sum_{f=1}^{p}|x_{if} - x_{jf}|\]

Minkowski distance (Lₕ norm): \[d(i,j) = \\left(\\sum_{f=1}^{p}|x_{if} - x_{jf}|^h\\right)^{1/h}\]

Supremum distance (L∞): \[d(i,j) = \\max_f |x_{if} - x_{jf}|\]

Metric properties (Euclidean & Manhattan satisfy all): 1. Non-negativity: d(i,j) ≥ 0 2. Identity: d(i,i) = 0 3. Symmetry: d(i,j) = d(j,i) 4. Triangle inequality: d(i,j) ≤ d(i,k) + d(k,j)

```python from scipy.spatial.distance import euclidean, cityblock, minkowski, chebyshev

x, y = [1, 2, 3], [4, 6, 5] print(f”Euclidean: {euclidean(x, y):.2f}“) print(f”Manhattan: {cityblock(x, y):.2f}“) print(f”Minkowski (h=3): {minkowski(x, y, 3):.2f}“) print(f”Supremum: {chebyshev(x, y):.2f}“) ```

Weighted Euclidean: \[d(i,j) = \\sqrt{\\sum_{f=1}^{p}w_f(x_{if} - x_{jf})^2}\]

Ordinal Attributes

Three-step process:

  1. Rank: Replace values with ranks \(r_{if} \\in \\{1, \\ldots, M_f\\}\)
  2. Normalize: Map to [0,1] \[z_{if} = \\frac{r_{if} - 1}{M_f - 1}\]
  3. Compute distance: Use numeric distance measures on \(z_{if}\)

```python from sklearn.preprocessing import OrdinalEncoder

Example: satisfaction levels

satisfaction = [[‘fair’], [‘excellent’], [‘good’], [‘excellent’]] encoder = OrdinalEncoder(categories=[[‘fair’, ‘good’, ‘excellent’]]) ranks = encoder.fit_transform(satisfaction).flatten()

Normalize to [0,1]

M = 3 # number of states z = (ranks) / (M - 1) print(f”Normalized: {z}“) ```

Mixed Attribute Types

Combined dissimilarity: \[d(i,j) = \\frac{\\sum_{f=1}^{p} \\delta_{ij}^{(f)} d_{ij}^{(f)}}{\\sum_{f=1}^{p} \\delta_{ij}^{(f)}}\]

Indicator \(\\delta_{ij}^{(f)} = 0\) if: - Either value is missing, OR - Both values are 0 for asymmetric binary

Contribution \(d_{ij}^{(f)}\): - Numeric: \(\\frac{|x_{if} - x_{jf}|}{\\max_h x_{hf} - \\min_h x_{hf}}\) - Nominal/Binary: 0 if match, 1 if mismatch - Ordinal: Treat as numeric after normalization

```python def mixed_dissimilarity(obj1, obj2, attr_types, ranges): ““” attr_types: list of ‘numeric’, ‘nominal’, ‘ordinal’, ‘binary’ ranges: dict with normalization ranges for numeric attributes ““” total_delta = 0 weighted_sum = 0

for i, (v1, v2, atype) in enumerate(zip(obj1, obj2, attr_types)):
    if pd.isna(v1) or pd.isna(v2):
        continue
    
    delta = 1
    if atype == 'numeric':
        d = abs(v1 - v2) / ranges[i]
    elif atype in ['nominal', 'binary']:
        d = 0 if v1 == v2 else 1
    else:  # ordinal (pre-normalized)
        d = abs(v1 - v2)
    
    weighted_sum += delta * d
    total_delta += delta

return weighted_sum / total_delta if total_delta > 0 else 0

```

Cosine Similarity

For sparse, high-dimensional vectors (documents, term-frequency):

\[\\text{sim}(x,y) = \\frac{x \\cdot y}{||x|| \\cdot ||y||}\]

where \(||x|| = \\sqrt{x_1^2 + x_2^2 + \\cdots + x_p^2}\)

Range: [0, 1] - 0 = orthogonal (no similarity) - 1 = identical direction (maximum similarity)

Tanimoto coefficient (binary variation): \[\\text{sim}(x,y) = \\frac{x \\cdot y}{x \\cdot x + y \\cdot y - x \\cdot y}\]

```python from sklearn.metrics.pairwise import cosine_similarity

Document term-frequency vectors

doc1 = [5, 0, 3, 0, 2, 0, 0, 2, 0, 0] doc2 = [3, 0, 2, 0, 1, 1, 0, 1, 0, 1]

sim = cosine_similarity([doc1], [doc2])[0][0] print(f”Cosine similarity: {sim:.4f}“) ```

```{note} Cosine similarity is a non-metric measure—it doesn’t satisfy all metric properties but is highly effective for sparse data. ```

Summary

```{important} ### Key Takeaways

  1. Match measure to attribute type
    • Nominal → Mode
    • Ordinal → Mode, Median
    • Numeric → Mean, Median, Mode
  2. Visualize before analyzing
    • Plots reveal patterns, outliers, distributions
    • Multiple views provide different insights
  3. Choose appropriate distance
    • Euclidean: Dense continuous data
    • Manhattan: Grid-like spaces, robust to outliers
    • Jaccard: Sparse binary data
    • Cosine: High-dimensional sparse vectors (documents)
  4. Handle outliers strategically
    • Use robust measures (median, IQR)
    • Apply trimming or winsorizing
    • Consider transformation (log, sqrt)
  5. Consider data characteristics
    • Symmetric vs asymmetric
    • Discrete vs continuous
    • Sparse vs dense
    • Scale differences → normalize ```
